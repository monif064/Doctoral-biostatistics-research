# HPC and SLURM Workflows

This folder contains selected high-performance computing (HPC) materials used to conduct large-scale simulation studies for my doctoral research.

The simulations were run on Compute Canada infrastructure, now managed by the Digital Research Alliance of Canada. The computing environments included the **FRONTENAC** cluster and other former Compute Canada systems that were later retired or replaced as the national research-computing infrastructure changed.

## Planned Contents

- SLURM job-submission scripts
- Batch simulation workflows
- Parallel computing procedures
- Computing resource specifications
- Reproducibility instructions
- Examples showing how simulation jobs were organized and executed on Compute Canada clusters
