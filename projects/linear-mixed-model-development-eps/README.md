# Linear Mixed Model Development for Extreme Phenotype Sampling

This project contains selected code and supporting materials from the development and evaluation of a linear mixed model method for correcting population structure in studies using extreme phenotype sampling (EPS).

## Methods Explored

- Linear mixed models
- Expectation-Maximization algorithms
- Monte Carlo methods
- Likelihood-ratio tests
- Wald tests
- Simulation-based model evaluation

## Planned Contents

- Selected R scripts
- Simulation procedures
- Estimation and inference methods
- Summary results and figures
- Reproducibility documentation

Materials will be added gradually after review and preparation for public sharing.
