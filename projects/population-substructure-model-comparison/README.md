# Mixed-Model Approaches for Population Substructure

This project contains selected R code and supporting materials related to the comparison of mixed-model-based approaches for correcting population substructure, with application to extreme phenotype sampling.

The work is associated with the publication:

*Comparison of mixed model based approaches for correcting for population substructure with application to extreme phenotype sampling.*

## Planned Contents

- Selected R scripts
- Simulation methods
- Model comparison procedures
- Figures and summary results
- Reproducibility documentation

Materials will be added gradually after review and preparation for public sharing.
